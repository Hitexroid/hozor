# حضور و غیاب — راهنمای سریع

1. فایل `index.html` رو توی ریپازیتوری‌ت آپلود کن (یا با GitHub Pages فعالش کن، یا مستقیم از روی دیسک باز کن).
2. یه Personal Access Token با دسترسی `repo` (یا برای فاین‌گرین: Contents: Read & Write) بساز.
3. فایل رو باز کن، از منوی ☰ بالا سمت چپ:
   - نام کاربری/سازمان گیت‌هاب
   - نام ریپازیتوری
   - نام برنچ (پیش‌فرض main)
   - مسیر فایل داده (پیش‌فرض data.json — نیازی نیست از قبل بسازیش، خودش می‌سازه)
   - توکن
   - بزن «ذخیره تنظیمات»
4. از این به بعد همه‌چیز خودکار ذخیره میشه، نیازی به دکمه‌ی ذخیره نیست.

نکته: اگه از GitHub Pages استفاده می‌کنی، توکن توی localStorage مرورگر خودت ذخیره میشه (نه توی کد)، پس با هرکسی که این توکن رو بهش ندی نمی‌تونه بهش دسترسی داشته باشه.
